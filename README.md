# SmartBudget Manager

## Description
SmartBudget Manager is an Excel workbook designed to help users manage their monthly budget. It allows users to record income and expenses, categorize expenses, calculate the monthly balance, and visualize expenses using charts.

## Features
- Record monthly income and expenses.
- Organize expenses by category.
- Calculate the monthly balance automatically.
- Display charts of expenses by category.
- Receive warnings when the budget limit is exceeded.

## Requirements
- Microsoft Excel 2016, 2019, 2021, Microsoft 365, or a compatible spreadsheet application.

## Getting Started
1. Open the SmartBudget Manager Excel workbook.
2. Go to the Transactions worksheet.
3. Enter your income and expenses.
4. Select the appropriate expense categories.
5. Open the Dashboard worksheet to view your monthly balance and charts.

## Worksheets
- **Dashboard:** Displays monthly balance, total income, total expenses, and charts.
- **Transactions:** Allows users to enter income and expenses.
- **Categories:** Contains predefined expense categories.

## Notes
Save your workbook regularly to keep your budget information up to date.
